## Installer fix

v0.17.1 changes only the install script; the server is the same as v0.17.0.

## Fixes

- **The installer looked frozen while downloading.** The binary (about 70 MB on macOS) downloaded silently, so a slow connection looked like a hang. The installer now shows the file size and a progress bar when run in a terminal. A download that stays under 100 KB/s for 30 seconds is retried on a new connection; if it is still slow, a final attempt runs without the speed check so it can finish.

## Upgrade notes

- Nothing to change. Re-run `curl -fsSL https://get.vaultbase.dev | sudo sh` to upgrade an existing install.
