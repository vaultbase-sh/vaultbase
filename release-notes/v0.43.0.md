## Record writes from server code, reorderable rate limits

v0.43.0 lets hooks, custom routes, cron jobs and queue workers write records the way the API does, lets you put rate limit rules in the order you need, and makes upgrades and installs checked on every release. No breaking changes.

## Added

- **`helpers.records.create / update / delete`** for hooks, routes, jobs and workers. The write goes through the records path, so it is validated, runs the target collection's hooks, and gets record history, realtime events and webhooks. `helpers.sql` still writes rows directly and gets none of those. No API rules apply (it is trusted server code), and history shows the write as system. A hook that triggers itself is stopped after 5 nested writes instead of looping. See [hooks](https://docs.vaultbase.dev/concepts/hooks/#helpersrecords).
- **Reorder rate limit rules** in Settings → Rate limiting, by drag or with up/down arrows. Rules are checked top to bottom and the first match applies, so order decides which limit a request gets. Counters are now kept per rule, so reordering doesn't mix them.
- **[Compatibility page](https://docs.vaultbase.dev/reference/compatibility/)**: platforms, databases, which SDK versions go with which server, upgrades and deprecations.

## Fixed

- **`install.sh --verify-sig` under `sudo`** explains why `cosign` may not be found (sudo resets `PATH`) and how to fix it.
- **Realtime:** the SDKs' `__flags` subscription no longer gets an `unknown_collection` warning.

## Tests and releases

- **Upgrades are tested from every minor since 0.24**, on SQLite and Postgres: 28 new fixtures made by the real releases. In-place upgrades are supported from v0.24.0.
- **Every release is installed the way users do** (Ubuntu with a systemd service and a signature check, Ubuntu and Alpine containers with and without `xz`, Windows) and checked to start and answer. The check also runs weekly.

## SDKs

No SDK release is needed. JS SDK 0.11.0, and Dart `vaultbase` 0.7.0 with `vaultbase_flutter` 0.1.6, work with this release.

See the [changelog](https://docs.vaultbase.dev/changelog/) for the full list.

## Upgrade notes

- None. Upgrades are supported from v0.24.0; from an older install, upgrade to 0.24.x first.
