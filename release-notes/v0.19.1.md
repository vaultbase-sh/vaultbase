## Admin auth cleanup

v0.19.1 moves every admin route onto one shared auth check. Nothing changes for a request with a valid admin token; two small differences for the rest are below.

## Changes

- **401 instead of 403 without a valid admin token** on CSV import and export, creating, updating and deleting collections, the view query previews and collection stats, like every other admin route. A client that treated 403 from these routes as "sign in again" should treat 401 the same way (the admin UI and the SDK already do).
- **An API token sent with its `vbat_` prefix is accepted on every admin route.** Some only accepted it without the prefix.
- A test now calls every admin route without a token, so a new route that forgets the check fails CI instead of shipping open.
