## A smaller download from the Linux installer

v0.40.1 fixes one installer bug. Nothing in the server changed.

## Fixed

- **The Linux installer downloads the compressed binary whenever `xz` is installed.** Before downloading, it checked for the `.xz` file with a separate request. If that request timed out or was refused (a slow link, a proxy), the installer fell back to the raw binary: about 125 MB instead of 50. Now the download of the `.xz` file itself decides, and the installer falls back to the raw binary only if that download fails. Both paths check the same checksum and signature.

`get.vaultbase.dev` serves the installer from the latest release, so new installs get the fix right away. An existing install doesn't need to update for it.

## SDKs

No SDK release is needed. JS SDK 0.10.0, and Dart `vaultbase` 0.6.0 with `vaultbase_flutter` 0.1.5, work with this release.

See the [changelog](https://docs.vaultbase.dev/changelog/) for the full list.
