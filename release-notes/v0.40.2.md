## A smaller download from `vaultbase update`

v0.40.2 fixes the built-in updater the way v0.40.1 fixed the installer. Nothing else changed.

## Fixed

- **`vaultbase update` downloads the compressed binary.** It always downloaded the raw binary, about 125 MB, even where the release has a `.xz` and `xz` is installed. On Linux it now downloads the `.xz` (about 50 MB) and decompresses it, and falls back to the raw binary if that fails. The checksum and signature are checked on the result as before.

The installed version is the one that downloads, so this takes effect from the update after this one. Updating to v0.40.2 itself still downloads the raw binary. For the smaller download now, re-run the installer, which upgrades in place: `curl -fsSL https://get.vaultbase.dev | sudo sh`.

## SDKs

No SDK release is needed. JS SDK 0.10.0, and Dart `vaultbase` 0.6.0 with `vaultbase_flutter` 0.1.5, work with this release.

See the [changelog](https://docs.vaultbase.dev/changelog/) for the full list.
