## Signature bundles, and a maintenance-mode fix

A small release. It moves release signatures to the format current cosign expects, and fixes the message clients see when maintenance mode turns on.

## Changed

- **Releases carry a Sigstore bundle** (`<asset>.sigstore.json`) next to each `.sig` / `.pem`. cosign 3 deprecates the `--certificate` / `--signature` flags. The installers, `vaultbase update` and the Docker image build now verify with the bundle when a release has one, and fall back to the pair for older releases. The release workflow verifies every bundle before publishing.

## Fixed

- **Turning maintenance mode on with a message could show clients the default message.** A settings save now writes every `*.enabled` switch after the values it acts on, so the message is in place before maintenance closes connections.

## SDKs

No SDK changes: JS SDK 0.10.0 and Dart `vaultbase` 0.6.0 (with `vaultbase_flutter` 0.1.5) work with this release.

See the [changelog](https://docs.vaultbase.dev/changelog/) for the full list.
