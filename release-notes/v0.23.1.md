## The setup wizard shows the database

v0.23.1 makes the database choice visible at setup and fixes the setup and sign-in pages on narrow screens. No configuration changes.

## Changes

- **The setup wizard shows the database.** Its first step says whether the server runs on SQLite or Postgres, and how to switch before the first admin is created: stop the server, set or remove `VAULTBASE_DATABASE_URL`, and start it again. The installation guide and quick start now start with the same choice.

## Fixes

- **The setup and sign-in pages on narrow screens.** The card kept its 640-pixel width below that and was cut off on phones.
