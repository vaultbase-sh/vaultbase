## Slow realtime clients no longer grow the server's memory

v0.24.1 fixes a memory problem found by a realtime load test. No configuration changes.

## Fixes

- **A WebSocket client that stops reading is disconnected.** Every realtime event was buffered for a client that had stopped reading, without limit: in the load test, 50 such clients held about 150 MB, and one address may open 100 realtime connections. A socket more than 1 MB behind is now cut off, as SSE clients already were. Clients that keep up are unaffected and keep receiving every event; a disconnected client reconnects and refetches, as after any disconnect.
