## List totals under mixed workloads

v0.21.3 keeps list totals cached while other collections are being written, and adds two deploy notes. No configuration changes.

## Changes

- **List totals stay cached across writes to other collections.** Every write used to empty the whole totals cache, so under a mixed workload every list recounted its total. Record and user writes now report their table, and only that collection's totals are recounted; raw SQL from a hook or the SQL page still empties everything. Inside a transaction the cache answers but is not filled.
- **Deploy notes.** The nginx template's header says to raise `worker_connections` (Ubuntu's default of 768 per worker shows up as 500s at a few hundred concurrent clients), and the deploy README warns against cron jobs that drop the page cache, which evict the memory-mapped database.
