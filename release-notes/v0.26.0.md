## An HTTP client in the admin, a quieter sidebar, a Docker image

v0.26.0 turns the admin's API preview into a small HTTP client, keeps advanced pages out of the sidebar until you use them, and publishes an official Docker image with templates for Docker Compose, Render, Fly.io and Railway.

## New

- **API preview as an HTTP client.** Several requests open at once, with Params (kept in step with the URL), Headers, and a JSON or form-data body. Send as the admin, as a user signed in from an auth collection, with a token, or with no auth, to check your rules the way others meet them. The response shows status, time, size, headers and body, and any request copies as Vaultbase SDK code, `fetch()` or curl. History stays in your browser; saved requests are kept on the server for each admin.
- **Endpoints from the OpenAPI spec.** The preview lists what the server actually serves for each collection: sign-in routes for auth collections, GET and PATCH for singletons, reads for views.
- **Export** the API as an OpenAPI spec, a Postman collection, an Insomnia export or a `.http` file.
- **Sidebar favorites.** Star a page to put it at the top. Favorites follow you across browsers.
- **Docker image** at `ghcr.io/vaultbase-sh/vaultbase` for amd64 and arm64, built from each release's checked binaries, with a Compose file that adds HTTPS through Caddy, and templates for Render, Fly.io and Railway. See the deployment guide.

## Changes

- **A shorter sidebar.** Feature flags, Webhooks, API tokens, Monitoring, API preview, SQL and the audit log appear once they're in use, open, a favorite, or pinned in Settings → Sidebar. **More** lists the rest, and ⌘K reaches every page. Nothing is disabled.

## Fixes

- The OpenAPI spec no longer offers a create operation for auth collections, which the server refuses; users are created through register.
- The API preview's default request was a 404.
- On Postgres, closing the database waits for settings writes still in flight.

## Upgrade notes

- Some admin pages leave the sidebar until they're used; find them under **More** or with ⌘K, or pin them in Settings → Sidebar.
- Clients generated from the OpenAPI spec lose the create method for auth collections; it never worked.
